# 배경 사진

로그인·앱선택 화면의 배경. **새로고침할 때마다 이 중 하나가 무작위로 뜬다.**

- 목록은 `../../index.html`의 `BG_PHOTOS` 배열이 정본이다. 지금은 `2.webp`·`3.webp` 두 장
- **직전에 쓴 사진은 빼고 고른다.** 그냥 무작위로 뽑으면 같은 사진이 연달아 나와
  새로고침해도 안 바뀐 것처럼 보인다. 두 장뿐인 지금은 매번 번갈아 나온다
- 사진을 빼거나 늘리려면 그 배열만 고치면 된다. 배열을 비우면 CSS 그라디언트만 남는다
- 없는 파일을 가리켜도 화면은 깨지지 않는다 — 로드에 실패하면 조용히 그라디언트로 남는다

번호가 2·3부터 시작하는 것은 처음 후보 6장 중 이 둘만 남겼기 때문이다. 아래 변환기는
넘긴 순서대로 `1.webp`부터 다시 매기므로, 다시 돌릴 때는 배열의 파일명도 함께 맞출 것.

## 넣는 방법

원본(JPG/PNG)을 WebP로 줄여서 넣는다. 1920px 폭, 품질 75면 보통 200KB 안팎이다.

```bash
python -X utf8 tools/make_bg.py <원본 파일들...>
```

밤하늘 사진은 어두워서 화질 손실이 잘 안 보이므로 품질을 더 낮춰도 된다.
